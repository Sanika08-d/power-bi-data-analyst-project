# Sales Data Analysis using Power BI

## Project Overview
This project focuses on analyzing sales data using Microsoft Power BI to identify sales trends, product performance, and business insights.

## Objective
- Analyze sales performance
- Identify top-performing products
- Understand sales trends
- Create interactive dashboards
- Generate meaningful business insights

## Tools & Technologies
- Microsoft Power BI
- Power Query
- DAX
- Microsoft Excel

## Key Features
- Interactive sales dashboard
- Sales performance analysis
- Product-wise analysis
- Trend analysis
- Data visualization

## Conclusion
The Power BI dashboard provides an interactive way to analyze sales data and helps in understanding important business trends and performance.
